# Guía de respaldo y restauración

## Crear un respaldo
1. Ajustes → **Respaldo y restauración**.
2. Escribe una frase de recuperación (mínimo 12 caracteres) o pulsa **Generar una frase segura**.
3. **Guarda la frase fuera del teléfono** (papel o gestor de contraseñas) y marca la casilla.
4. **Crear y compartir respaldo**: elige dónde guardar el archivo `.cuotiva` (Drive, correo, WhatsApp…).

El archivo incluye todos tus datos y comprobantes. No incluye el PIN. Si pierdes la frase **no hay
forma de abrirlo**.

## Restaurar
1. En el teléfono nuevo (o tras reinstalar) abre Cuotiva → Ajustes → Respaldo y restauración.
2. **Elegir archivo de respaldo** e ingresa la frase.
3. Revisa el resumen (fecha y cantidades) y confirma. **Se reemplazan todos los datos del dispositivo.**
4. La app se reinicia con los datos restaurados. Antes del cambio se guarda una copia de lo anterior
   y, si algo falla, se revierte solo.

## Errores comunes
- «Frase incorrecta o archivo alterado»: revisa mayúsculas/espacios; si el archivo se editó o dañó, no abrirá.
- «Versión más nueva»: actualiza Cuotiva e inténtalo de nuevo.

## Recomendación
Haz un respaldo después de cada jornada de cobros importante y guarda al menos dos copias.
